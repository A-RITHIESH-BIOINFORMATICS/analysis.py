# 🧬 Automated DNA Sequence Analyzer & Mutation Tracker

[![License: MIT](https://shields.io)](https://opensource.org)
[![Python Version](https://shields.io)](https://python.org)
[![Field](https://shields.io)](https://wikipedia.org)

An automated computational biology pipeline built in Python to process raw nucleotide sequences, calculate structural stability metrics, and locate single-nucleotide polymorphisms (SNPs) across genetic datasets. 

Developed by a **Class 12 student (PCB stream)** to demonstrate foundational skills in algorithmic thinking, data parsing, and molecular biology rules.

---

## 🎯 Core Features

*   **DNA to RNA Transcription:** Automated molecular conversion mapping by replacing Thymine (T) with Uracil (U) bases.
*   **GC-Content Metric Calculation:** Computes structural stability percentages, a key indicator used to identify gene-dense regions in target organisms.
*   **Variant & Mutation Scanner:** Programmatically aligns healthy reference sequences against patient reads to isolate and report single-nucleotide mutations.

### 2. Run the Analysis Engine
